# 将来のゲーム作成ツール構想

利用者が自由にJRPG風ゲームを作れるツールを目標にする。具体的な編集画面・戦闘・イベント・保存の設計は現在の研究対象外。

|区分|将来の想定|
|---|---|
|ツールの利用環境|横向きタブレット・PC|
|ゲームの実行環境|スマホ（縦横対応可能）、タブレット、PCのブラウザ|
|描画頻度|30fps・可変fps等を選べる余地|
|仲間の移動|隊列に加え、並走・追い抜きを自律的に行う同行|
|見た目の設定|輪郭線、照明・影・ブルーム等の絵作りは利用者が調整|
|内部負荷|光・影の計算優先度や品質配分はツール側で自動対応する方向|

今はデータ駆動、パラメーター生成、描画とロジックの分離、複数キャラ、将来の視点拡張を妨げない構造を意識する。エディターや完全なバージョン付き保存形式を先行実装しない。
自律同行AI・戦闘照明演出の編集機能は将来要望。v6で動く光や複数キャラを確認しても、それらのシステムが完成したことにはならない。
