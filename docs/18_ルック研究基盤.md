# ルック研究・工程1：同条件比較の基盤

2026-11-08 JST。[Issue #13](https://github.com/formulaText/pixel-rig/issues/13)。V6-03後・V6-04前の追加工程。実機確認は工程2を含む候補でまとめる。機能の完成は画風の採用ではない。

## 状態と描画

研究値・プレビュー条件・時刻を1つのschema 1文書にまとめ、頭角度、頭形状、顔、待機調整の置き場を分離。通常設定から読み戻さず、研究画面を閉じると採用済みBの通常設定に復帰する。基準と調整中は同じ時計・向き・照明で比較し、基準を選んでも編集中データを失わない。

既存ReplayClockを使い60Hzの固定更新・停止・1コマを共有。縦斜めは既存再生経路、8方向は0から45度ずつ2秒の固定順。歩行の速度・振幅を待機操作で変更しない。頭全体を傾け、顔の画像だけを画面変形しない。頭と胴体の上下動の差は首より上のローカル位置で補正し、顔・髪を同じ頭グループに保持。

ドット表示は同じrenderWorld/B（足元相対輪郭深度・24bitの共有色深度）を使用。3D確認は同じリグ・時刻・顔アンカーの高解像度色targetを表示し、ドット輪郭処理を省く。非表示側の最終表示は描画しない。高解像度確認にも顔の現行スタンプ方式が残る点は、工程2で構造化した顔との比較に記録する。画像検査以外でreadPixelsを呼ばない。毎フレームのモデル・テクスチャ生成なし。

キャラの外周線と内部線は既存シェーダーが区別しているので不透明度を独立調整。RGBの線合成率だけを変え、本体のalphaや背景線、深度を変えない。共通の線色を使用。元のGLSLと関数は保存し、研究用の合成シェーダーを別ファイルに隔離する。既定色は元の浮動小数値を保持し、HTML色の8bit丸めで基準を変えない。

## 研究内の範囲

|項目|範囲・初期値|用途と限界|
|---|---|---|
|頭の上向き|0〜12度、0|頭全体、全方向に同じローカル回転。方向境界で跳ねない|
|頭／胴体の待機振幅|0〜1.5倍、1|歩行と別。0と現状を比較|
|待機速度|0.25〜2倍、1|既存待機の時間のみ変更|
|外周／内部線不透明度|0〜1、1|背景を変更せずキャラ線だけ|
|線色|RGB、現状|標準は元の(0.10,0.06,0.17)|
|口|なし／あり、なし|工程1は小さな口の比較。工程2で構造化・編集|

これらはプレビューで接続を比較するための暫定範囲で、最終画風の仕様ではない。日本語ラベル・現在数値入力・項目ごとの初期値復帰を用意。縦持ちはプレビューの下、横持ちは横にスクロール可能な操作欄を置く。2／3倍の拡大はnearestを維持する。

## 設定

名前付き30件までを端末内に保存。スキーマ、ビルドID、調整値、プレビュー条件、固定更新コマ数、停止状態をコピーする。元データを検証してから適用し、未対応版・不正値は理由を示して拒否。保存領域が壊れている場合は勝手に上書きしない。容量不足・クリップボード拒否を成功表示しない。コピーできない場合は内容欄の手動選択も使える。PNG・ファイルダウンロードを前提にしない。工程2で形式を拡張する際はschema 1からの移行を用意する。
