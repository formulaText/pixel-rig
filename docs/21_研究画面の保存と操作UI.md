# 研究画面の保存と操作UI（Issue #17）

## 実機結果と範囲

依頼者のiPhone 17 Safari、`gh-42445476163-1-7d4b99e0eedd` では、閉じ目方式切替で意図せず目が縮む修正と、顔全体位置の変更・初期値復帰を確認済み。研究画面全体の採用承認ではない。保存は一覧に名前が出ず未確認。PR #16を保持し、その上の専用ブランチで保存・UIを修正する。輪郭処理はIssue #18の別依存PRで追跡する。

## 保存の調査と修正

再生時刻36001フレーム（10分超）で保存すると、旧検証の上限36000によりlocalStorageへ書く前に拒否される。時刻0の保存は一覧へ反映された。これは再現できた原因であり、報告された端末での経過時間・保存制限は不明なので、実機の全原因と断定しない。

上限を24時間へ広げ、長い時刻の復元は既存の固定刻み再生を分割し、進捗と処理中表示を出す。その間は編集を止める。保存キー `pixel-rig-look-library-v1` と既存データを保持し、不正な保存領域を空で上書きしない。書き込み後に同じ文字列を読み戻してから一覧へ追加・選択し、保存済みと表示する。容量・権限の失敗は日本語の理由と設定コピーによる退避手順を表示する。

保存対象は顔の絵柄・配置・頭・動き・描画設定・プレビュー条件・保存時刻・停止状態。保存状態は設定変更で未保存へ切り替える。再生中の時刻進行だけでは未保存表示にしない。ブラウザ保存と文字データのコピーを区別し、ファイル書き出しもPNG保存も追加しない。

## 新しい画面

「全体 → 頭 → 顔 → 髪 → 胴体・動き → 描画」。顔は「全体配置 → 眉 → 目・ハイライト → 鼻の基準位置 → 口」。絵柄編集は共通の作業領域へ移動する。基本値の後に細かなまばたき・ハイライト設定を置く。

プレビューの下に比較・表示・再生、保存状態・保存ボタン、操作結果を固定する。結果文の長さでプレビューの寸法を変えない。縦は上にプレビュー、横とタブレットは左にプレビュー・右に設定。8方向ボタンは自動方向切替と分離し、選択状態を明示する。短い選択肢は表示されたボタンで選び、押下状態を表示する。

「この顔をコピーして編集」は顔プリセットだけを適用。「現在の設定を別名で保存」は研究設定全体を実際に別名保存する。「この端末のブラウザに保存」と「設定コピー・貼り付け（文字データ）」を区別する。
