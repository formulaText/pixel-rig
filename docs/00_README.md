## 優先順位と資料の役割

1. 依頼者の最新の明示指示。
2. 09の最新の判断記録と06の現行原則。
3. 12の計画と指定Issueの作業範囲・条件。
4. 01、04、05、07、08の説明。
5. 03とprototypes/v5は「v5の再現」を判断する基準。将来の方式を固定する根拠ではない。
6. 02とarchive/は当時の事実・判断の記録。現行要件を上書きしない。

現行資料同士に不一致を見つけた場合は、黙って都合のよい記述を採用せず、影響する作業を明示して整理する。
最初のマイルストーンはv5相当の再現。後続の見た目・方式は比較実装と依頼者の判断で確定する。
