# 11 用語集

| 用語 | 意味 |
|---|---|
| 論理解像度 | ドット1つを1画素として描く内部解像度。画面サイズ÷ドットの大きさで決まる |
| ドットの大きさ | 1ドットを何CSSピクセル(実際は整数デバイスピクセル)で表示するか |
| S | キャラの解像度(キャラ単体を描く正方形のピクセル数)。1ピクセルのワールド長を決める基準 |
| ピクセル空間(PS) | 画面の右・上方向の整数ピクセル座標。カメラの整数オフセットを足してワールドに固定したもの |
| カメラ基底 | カメラの右・上・手前方向のベクトル。シェーダーの計算の基準 |
| 変換ステップ①〜④ | ①トゥーン階調 ②半透明の排除 ③輪郭線 ④ちらつき対策(4コマ・スナップ) |
| 深度ルール | 物体ごとの前後関係の決め方。3D/手前の板/奥の板/地面 |
| 手前の板 | 足元の範囲のうちカメラに最も近い点を通る垂直な板に深度を寄せる方式(キャラ・小物) |
| 奥の板 | 足元の範囲のうち最も遠い点を通る板に寄せる方式(v5の壁。v6で壁への適用を外す試行を予定。方式自体の全面削除は未決) |
| 本来の深度 | 板に寄せる前の3D上の深度。輪郭線判定に使う。v5は分類IDによる判定であり、物体固有の識別ではない |
| カメラ方向投影 | 模様を「画面の1ピクセル=模様の1マス」で平面に写す方式 |
| 展開マッピング | 円柱などの曲面で、軸からの距離を使って曲面上の座標を復元して模様を写す方式 |
| ドット顔 | 目や眉の位置だけを3Dから求め、ドット絵の目・眉を画面に直接描き込む方式 |
| 感情表現 | 頭上アイコン+全身モーション+目・眉の変化の組み合わせ |
| 描き込み層(デカール) | 手描きのドット絵をワールドの位置に貼る層 |
| 色ランプ | 素材ごとの5段階の色(影側は青紫寄り、明側は黄寄りに色相シフト) |
| ちらつき検査 | 移動中に静止物の画素が不規則に変化しないかを確認する検証 |
| G-buffer | ディファードレンダリングで、照明前に描き出す色・法線・深度などのバッファ |
| シェルテクスチャリング | 面を少しずつずらして何層も重ね、ノイズで切り抜いて毛や草を表現する手法 |
| マーチングスクエア | 格子の角の値から境界線を補間して作る手法。斜め・カーブの地形境界に使う |
| SDF | 境界までの距離を表す関数・データ。描画と当たり判定の共通データに使う |

## 今回追加・明確化した用語

|用語|意味|
|---|---|
|分類ID|キャラ・建物・小物などの種類を区別する値。個体識別ではない|
|物体ID|別々のキャラや小物を区別する値。v5の分類IDだけでは代用できない|
|共通ドット格子|キャラと背景の1ドットの大きさを揃える基準|
|寸法比|キャラに対するタイル・建物・道等の大きさの関係|
|発光面＋代表光源|面の見た目と、周囲の照明を計算する代理光源を分ける近似|
|自動負荷配分|画面への影響から光と影の計算量を配分する検証案|
|節目|依頼者が実機で見た目・挙動・性能をまとめて判断する地点|
|比較可能|実装して比べられる状態。方式の最終採用とは別|
|回転|スマホの縦横変更と、マップを見る方向の回転を区別する|
