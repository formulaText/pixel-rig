# 03 現行実装(v5)技術仕様

本書はv5の実装記録であり、v6以降の固定仕様ではありません。v5は全体で1個の深度バッファしか持たないわけではなく、色パス・法線深度パス等に別ターゲットがあります。
輪郭線のIDは建物／キャラ／小物等の分類IDです。同じIDを「同じ物体」とみなすコードがあり、個々の物体を識別できるという意味ではありません。
Sは単体描画枠の解像度。キャラの実寸ドット数やタイル寸法と区別します。カメラ基底化も任意の角度・透視投影での検証完了を意味しません。


対象ファイル:`../prototypes/v5_pixel-rig-poc.html`(単体HTML、Three.js r128 を cdnjs から読み込み)

## 1. 描画パイプライン(1フレーム)

1. **ロジック更新**:60Hz固定ティック(1フレームで最大6ティック)。入力・移動・アニメ位相・表情・感情モーション。
2. **シャドウマップ**:太陽方向からの正射影カメラで、worldScene（背景。charSceneのキャラは含まない）の深度を 1024² の RGBA にパックして描画。カメラ位置はシャドウマップのテクセル単位にスナップ。
3. **カラーパス**(論理解像度 W×H):ワールド(地面・建物・小物を1シーンに統合)→ 描き込み層(デカール)→ 足元の影(乗算)→ キャラ。
4. **法線・深度・IDパス**:ワールド → キャラ。深度テクスチャ(描画上の前後)も同時に取得。
5. **後処理**(フルスクリーン1パス):半透明排除(②OFF時は4倍解像度からの単純縮小)、輪郭線、ドット顔・眉・頭上アイコンの描き込み。キャンバスへ直接出力。
6. **比較表示**(任意):キャラ単体を別カメラで S×S に描画し、readPixels で2Dキャンバスへ転送(偶数フレーム:段階比較、奇数フレーム:顔表現比較)。

## 2. 座標系と主要定数

| 定数 | 値 | 意味 |
|---|---|---|
| PITCH | 35° | カメラの見下ろし角(SINP/COSP はその sin/cos) |
| FR | 1.25 | キャラ単体カメラの半径(ワールド単位) |
| S | 16/24/32/48(既定32) | キャラの解像度。1ピクセルのワールド長 `texel = 2*FR/S` |
| T(タイルpx) | S/2 | 画面上のタイルの一辺(S=32で16px) |
| TW | 1.25 | タイルの横幅(ワールド) |
| TD | TW/SINP | タイルの奥行き(画面上で横幅と同じpx数になる) |
| TH | TW/COSP | 1タイル分の高さ(画面上で同じpx数になる) |
| マップ | 40×24タイル | ワールド原点がマップ中央 |
| ワールドカメラ | 正射影、距離50、near20/far80 | |
| キャラ単体カメラ | 正射影、near3.4/far6.6 | |
| STEP | 1/60秒 | ロジックの固定ティック |
| WALK_V | 2.8 | 横方向の歩行速度。縦は画面上で同速になるよう 1/SINP 倍 |
| CYCLE | 0.64秒 | 歩行1サイクル(④ON時は4コマに間引き) |
| PLAYER_R | 0.3 | 当たり判定の半径(v6で楕円化を試行予定（採否未確定）) |
| CHAR_FOOT_R | 0.15 | キャラの「手前の板」の足元半径 |
| 板の混合率 | 手前0.15/奥0.02 | 平坦化した深度と本来の深度の混合比 |
| シャドウマップ | 1024²、範囲±24 | |

**ピクセル空間(PS)**:画面の右方向・上方向の整数座標。`p = uPixOrigin + floor(gl_FragCoord.xy / uPixScale)`。
- カメラは整数ピクセル単位でのみ移動(`translateX/Y(cam * texel)`)。
- 画面幅・高さが奇数でもピクセル境界が整数に来るよう、正射影の left/bottom を `-floor(W/2)*texel` 等で非対称に設定。
- `uPixScale` は②OFF(4倍解像度描画)時に4。

**カメラ基底**:`uCamR`(右)・`uCamU`(上)・`uCamB`(カメラ側=手前)をワールドカメラの matrixWorld から毎フレーム取得。v5では値は固定だが、シェーダーはすべてこれを基準に計算しており、角度の固定値は残っていない(画面回転は未検証)。

## 3. 深度ルール(頂点シェーダー)

頂点属性 `aCard`(0:3D、1:手前の板、2:奥の板、3:地面)と `aFoot`(足元の範囲:中心xz+半幅。hz<0なら円)を持つ。

- **手前の板/奥の板**:カメラ側を向く水平方向 nh について、足元の範囲のうち最も近い点(手前)/最も遠い点(奥)を通る垂直平面を求め、頂点を視線方向に沿ってその平面上へ移動(画面上の位置は不変、深度だけ変わる)。その後、本来の位置と混合率で混ぜる。
- **地面**:`gl_Position.z = 0.9995 * w` で常に最奥。
- 割り当て:キャラ・小物・木=手前の板、建物の壁・扉・窓=奥の板、屋根・煙突・崖=3D、地面=地面。
- キャラはユニフォーム(`uFoot`)、ワールドは頂点属性で指定(`uCardSrc`で切替)。

## 4. 法線・深度・IDバッファと輪郭線

- RGBA8に「法線XY(各8bit)+本来の深度12bit+ID4bit」をパック。ID:1=建物・地形、2=キャラ、3=小物。
- 同時に深度テクスチャ(描画上の前後=平坦化後)を取得。
- 輪郭線の判定:4近傍について、**同じ分類ID同士は本来の深度差**(面の傾きに応じたしきい値付き)、**異なる分類ID同士は深度テクスチャ**で「どちらが手前か」を判定。
  - 手前の隣がキャラで自分がキャラ以外 → キャラの外周線(濃い色、隣の色を少し混ぜる)
  - 自分がキャラ → キャラ内部の線
  - それ以外 → 背景の控えめな線
  - 線にならない場合、法線差が大きく光源側の画素なら軽いハイライト

## 5. マテリアルと模様

- **色ランプ**:素材ごとに5段階(深い影・影・基本・明・ハイライト)。影側は青紫寄り、明側は黄寄りに色相シフト。全ランプを1枚のDataTexture(5×行数)に格納。
- **トゥーン階調**:半ランバート値を 0.8/0.5/0.3 で区切った段+模様の段オフセット → ランプのインデックス。
- **平面の模様**:カメラ方向投影。面ごとの起点(左上の角)を頂点属性で持ち、整数ピクセルに丸めて基準にする。
- **曲面の模様**:円柱の展開マッピング。画素中心のスクリーン座標と軸位置から θ=asin(rel) を求め、曲面上の点と高さを復元。展開の強さ(0=投影、1=完全展開)は既定値+物体ごとの上書き。
- **模様の種類**:レンガ、横板、縦板、瓦、石積み、樹皮。セルIDが隣の画素と変わる箇所に目地線を引く(圧縮されても線が消えない)。
- **地面**:タイル種別をDataTexture(40×24)で保持。画素→ワールドxz変換はカメラ基底から一般化済み。境界はバリューノイズで±T/4揺らしてなじませる。草の房、花、土の小石、砂の波紋、石畳、水の波(6fps)、岸の影と白波。
- **葉**:ボロノイ(セル約T*0.38px)を葉の塊とし、塊中心から疑似法線を作って照明。塊の外縁で切り抜いて凸凹のシルエット。一部の塊が3fpsで1px揺れる。

## 6. 照明

- 太陽:方向・色・強さ・環境光を時間帯プリセット(昼/夕方/夜)で切替。シャドウマップで遮蔽された面は段を下げる。
- 点光源:最大8個(街灯5個)。減衰を2×2ベイヤーディザで4段階に量子化。色は加算的な色味(tint)として乗算。
- 発光体:ランタン(照明計算を通さずランプの最明色)。
- 足元の影:ピクセル単位の楕円を乗算ブレンド(深度テストあり、深度書き込みなし)。

## 7. キャラクター

- プリミティブ製のデフォルメ人形(頭・髪・前髪・アホ毛・胴・マフラー・腕・脚)。階層:root → motion(感情モーション用)→ hips → torso/legs …。
- 歩行(4コマ間引き可)・待機(2コマ呼吸)は手続き的に計算。
- 顔:3D形状/UVデカール/ドット顔(既定)。ドット顔は目のアンカー位置を投影し、向きに応じて正面・細目・非表示を選択。眉は32px以上。肌の画素(α=0.6)にのみ目を描く。
- 表情:基準の目から細目・閉じ目を自動生成。自動まばたき(2〜6秒間隔、15%で2連続)。
- 感情表現:6種(喜び/驚き/疑問/落ち込み/怒り/焦り)= 頭上アイコン(9×9ドット)+全身モーション+目・眉。
- 移動:8方向・整数ピクセル単位(端数は蓄積)、斜めはX/Y同時。向きはヒステリシス+最短保持。④OFF時は比較用にアナログ移動。
- 当たり判定:円(半径0.3)対 円・矩形・水タイル。

## 8. 描き込み層(デカール)

- 手描きドット絵を文字列(1文字=1ドット、文字は色キー)で定義し、アトラス化。
- アンカー位置をピクセル格子に丸めた、画面平行の四角形として描画。地面置き(常に地面のすぐ手前)と立て置き(アンカーの深度)。
- 法線・深度パスには描かない(輪郭線なし)。

## 9. UI

時間帯/影、感情表現、曲面の展開の既定値、変換ステップ①〜④、顔表現の比較、段階比較、解像度、顔の表現、ドットの大きさ、自動歩行、比較更新、スプライトシート焼き出し(8方向×4コマのPNG)、HUD(fps・向き)。

## 10. コードの構成(単体HTML内の主なブロック)

定数 → シェーダー部品(C_COMMON/C_HASH/C_LIGHT/C_FOLIAGE)→ 各シェーダー(VS, TOON_FS, WORLD_FS, GROUND_FS, ND_FS, BLOB_FS, DECAL, POST)→ 共有ユニフォーム → 色ランプ → マテリアル工場 → キャラ構築 → マップ → ワールド構築(`put()` で頂点属性を付けて素材ごとに結合)→ 当たり判定 → デカール → 影 → シャドウマップ → 照明設定 → 顔・アイコン → 感情 → 後処理 → 描画関数 → 比較 → 再構築・リサイズ → 入力 → UI → 焼き出し → ロジック → メインループ。
