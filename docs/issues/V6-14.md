# V6-14：ドット粒子と発光粒子

目的：蛍・魔法・花びら・雨雪・火の粉・水しぶきの共通土台を作る。
依存：M4。
作業：seed付き粒子、寿命、色変化、重力、風、ピクセル位置への描画スナップを実装。粒子の発光と周囲への点光源を別設定にする。用途プリセットは描画の検証に必要な小規模例を用意。
守る条件：粒子ごとに必ず光源を生成しない。将来の共通風パラメーターに接続できる。水しぶきは粒子表現のみで、v8の水システムを実装しない。
受け入れ条件：同seedで再現。寿命後に資源が残らない。壁・キャラとの前後が破綻しない。表示粒子数と照明に使う粒子数を別計測。
実機確認：蛍、降る粒子、放射する粒子を切替。静止・移動・画面外からの出入りを確認。M5でまとめて確認。
