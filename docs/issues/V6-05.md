# V6-05：Three.js更新と再現確認【節目M1】

目的：新APIへ移行してもv5相当の見た目を維持する。
依存：V6-04の採用判断。
作業：承認した版へ固定更新。色空間の入出力、色ランプ、CanvasTexture、独自GLSL、深度テクスチャを移行。二重変換を防ぎ、最終出力での色変換の責任を明示。
守る条件：照明のリッチ化を同時に行わない。v5を再現する互換設定と、後続の線形照明用設定を混同しない。
受け入れ条件：M0の機能・画像・移動比較を通過。色差があれば原因と差分を提示し、許容を勝手に決めない。起動・回転・復帰でエラーがない。
実機確認：昼夕夜と顔・模様・影を旧版と比較。V6-03の操作・測定も確認しM1承認。
