# V6-13：階調・光の滑らかさ・ブルームの比較【節目M4】

目的：クッキリしたドット絵と滑らかな照明を両立する。
依存：V6-10〜12、V6-08の方式判断。
作業：滑らか／多段階／ディザの照明を切替。影・照射境界・ブルームの調整を分離。承認した範囲で照明だけ別解像度にする比較を実装。明るさ・色を時間で変える短い演出プリセットを作る。
守る条件：非発光の明るい模様まで意図せずブルームさせないよう発光マスクを分離。ブルームによるにじみと、遮蔽の誤りによる光漏れを区別。キャラ・背景の形と模様は整数格子を維持する。
受け入れ条件：昼屋外・夜の村・暗い室内で比較可能。8／16／32体の代表条件で測定。滑らかな光、輪郭線、ドット顔の組合せで視認性を確認。採用プリセットと保留事項を記録。
実機確認：静止画だけでなく横縦斜め移動で光と影の追従を見る。太陽・点・スポット・代理面の個別確認後に組み合わせを確認しM4承認。
