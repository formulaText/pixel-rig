# V6-08：G-bufferと合成方式の設計・最小検証

目的：低解像度ディファードのデータ契約を決める。
依存：M1、V6-07。
作業：アルベド、法線、本来の位置／深度、描画上の深度、分類ID、物体ID、素材情報、肌マスク、発光情報の保持方法を設計。候補の形式・精度・メモリ・パス数を表にする。色とデータの色空間を分離。小さい検証シーンで候補を試す。
守る条件：分類IDを物体IDとして流用しない。肌のα=0.6というv5固有表現を、不透明度や発光と混用しない。MRT上限や浮動小数レンダーターゲットの対応を実機診断に基づいて判断。地面・板・屋根で本来位置を正しく保持する。
受け入れ条件：低解像度照明をそのまま拡大する案と、照明効果のみ別解像度で合成する案の構成・費用・輪郭漏れ対策を提示。バッファの可視化と測定結果がある。
実機確認：板状深度のキャラに光を近づけ、3D位置に沿って照らされるか確認。依頼者がバッファ構成と比較実装の範囲を承認してからV6-09へ。
