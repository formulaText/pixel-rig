# V6-15：光と影の自動負荷配分【節目M5】

目的：絵作りの調整は利用者に残し、技術的な計算配分は自動化する。
依存：M4、V6-14。
作業：まず調整なしの固定基準を保存。画面への到達範囲、距離、減衰、周囲との明るさ／色差、役割、弱い光の集合を考慮する軽量な影響推定を実装。照明予算と影予算を分離。予算・評価式は実測から提案し、採用判断を記録。
守る条件：昼という理由だけで一律にランプを消さない。画面外の光源を無条件に消さない。プレイヤーから遠いという理由だけで出口や演出光を消さない。絵作りの指定値自体は書き換えない。日陰の判定を厳密計算しすぎて節約を打ち消さない。
作業詳細：候補の絞り込み → 照明と影の寄与を別評価 → 配分 → 安定化、の順を可視化する。入替の差に余裕を設け、最短保持時間とフェードを使う。切替中の二重計算の予算も計上。影を省く場合の壁越し光漏れ対策を方式比較し、必要な遮蔽は維持する。
受け入れ条件：自動なし／ありの比較で、屋外から日陰、ダンジョン、弱い光の集合、複数の接近光源、遠方の出口、光源の交差、急な演出を検証。影の点滅・順位の振動・移動影の引っ掛かり・光漏れを確認。節約の計測結果と見た目の差がある。
実機確認：同じ自動巡回をA/B再生。光源が同程度の影響になる境界で止まり、少し往復する。デバッグ表示を消した通常画面でも違和感がないか判断しM5承認。
