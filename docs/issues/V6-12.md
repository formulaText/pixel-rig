# V6-12：発光面＋代表光源による面光源近似

目的：正確な面光源計算を必須にせず、窓などの見た目を得る。
依存：V6-11。
作業：発光面と代理光源を独立データとして組み合わせる。中心点光源案と方向性を持つ代理案を比較。面のサイズ、明るさ、色、影の柔らかさの対応を説明する。
守る条件：面積に応じた物理的半影を再現したと称さない。点光源の6方向影の負荷が自動で消えるわけではない。代理光源を壁内部に置いて遮蔽させないよう位置と照射側を可視化する。
受け入れ条件：窓の近傍・遠方・斜めからの見え方、中心への明るさの集中、裏側への光漏れ、横切るキャラの影の比較がある。見た目と負荷の差から採用候補を提示。
実機確認：大小の窓前をキャラが横切る同一場面でA/B。M4で採否を判断。
