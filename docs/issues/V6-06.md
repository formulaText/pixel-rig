# V6-06：楕円当たり判定＋壁の3D深度の試行【節目M2】

目的：壁際の不自然な重なりを改善し、軒下の自由度を保つ。
依存：M1。
作業：画面の横に約0.48、地面の奥行きに約0.3の半径を持つ楕円を試す。壁・扉・窓を3D深度にし、建物の壁外形で判定する。旧方式との比較切替と当たり判定可視化を作る。円・矩形・角との接触、斜め移動の扱いを説明する。
守る条件：暫定案。矩形に対する判定を単純に両軸拡張しただけで厳密な楕円判定と称さない。半径は輪郭線・姿勢による幅も検証。実際のカメラ回転機能は作らない。
受け入れ条件：側面の壁への貼り付き・意図しない頭欠けを改善。軒下で屋根に頭が隠れる。正面・裏へ近づける。角での振動、ワープ、通路の不必要な封鎖がない。未達時は別案の検討結果を提出。
実機確認：各建物を一周、角へ斜めに接近、軒下へ進入、狭い通路を通過。旧方式との比較後に採否を決める。
