# V6-10：太陽・環境光・影・AOの比較

目的：昼夕夜と接地感の土台を作る。
依存：M3。
作業：太陽の向き・色・強度の時間変化、半球環境光、影の濃さ／境界の調整を実装。影の切り抜きを扱い、キャラの投影影と足元影の併用を比較。AOは独立切替できる検証機能として追加。
守る条件：影用カメラのテクセルスナップを維持。光の向きが動く場合まで位置スナップだけでちらつきが消えると仮定しない。AOは本来の位置と法線を使い、板の深度を実形状と誤認しない。接地影の二重暗化を防ぐ。
受け入れ条件：硬い影／柔らかい影、AOなし／ありの比較ができる。葉の見た目と影の差異を説明。時間停止と連続変化で点滅・影の浮き・輪郭漏れを検証。
実機確認：建物と木の脇を移動、時刻をゆっくり変化、キャラの足元を見る。後続V6-13とまとめてM4確認。
