# V6-09：ディファードの基本実装【節目M3】

目的：輪郭線と前後関係を保ったまま、形・素材と照明を分離する。
依存：V6-08の判断、M2の採否。
作業：承認構成のG-bufferと照明パスを実装。太陽と環境光から開始。既存模様の明暗オフセットを素材側の描き込みと照明側に整理し、再現用モードを残す。デカール・足元影・ドット顔の合成順を明示する。
守る条件：全体をぼかして代用しない。素材への描き込みの陰影をすべて消さない。将来の水・透過の専用合成経路を妨げないが、水を先行実装しない。
受け入れ条件：再現用モードと新モードの差分が説明できる。輪郭線・肌・葉の切り抜き・デカールが欠けない。8／16／32体の比較結果、通常描画の性能結果がある。
実機確認：v5再現モード、照明なし、照明ありを切替え、村・顔・重なりを確認。解像度／寸法比の候補も比較。M3で基盤の採否を判断。
