# V6-07：時間・複数キャラ・寸法設定の分離

目的：描画刷新の前に、1体と固定値への依存を整理する。
依存：M1。M2と競合する変更はM2採否を待つ。
作業：キャラごとに姿勢・顔・感情・ID・位置を管理。ロジックdt、表示頻度、アニメのコマ間隔を分離。8／16／32体の独立移動を作る。キャラ描画枠、タイル寸法、共通ドットのワールド寸法、表示倍率を別の設定に整理する。
守る条件：初期値では従来と同じ動作。現行60Hzからの変更を既定にしない。隊列AI・自律同行AI・オンラインは作らない。検証用移動とゲーム用経路探索を混同しない。
受け入れ条件：キャラごとの顔とアイコンが他人へ描かれない。交差・追い抜きで前後関係が安定。30／60／高リフレッシュ描画の比較でも同じ経過時間のロジック結果を維持。負荷で追いつけない場合は記録。
実機確認：8／16／32体を切替え、停止・交差・追い抜きを縦横で確認。解像度と寸法比の比較は別シーンで行い、通路幅が変わる効果を表示。M3でまとめて判断。


補足：複数キャラの顔・輪郭・前後を区別するIDの暫定実装をこのIssueに含める。V6-08で保存形式を再整理してよい。分類IDだけで個体を区別したとしない。
