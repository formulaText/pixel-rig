# V6-03：再現可能な検証・性能測定の基盤

目的：以後の変更の影響を比較可能にする。
依存：M0。
作業：時刻固定・1コマ進行・seed・入力再生・設定リセット・結果コピー・バッファ表示の土台を作る。静止場面、横縦斜め移動、壁際、木の重なりをプリセット化。CPU側の座標／時刻処理に必要な回帰検査を追加。
守る条件：通常画面で毎フレームreadPixelsしない。時間固定は見かけだけでなく瞬き・葉・水・粒子に一貫して適用する。v5の通常動作を維持。
受け入れ条件：同seed・同入力の再生が同結果になる。スクロール移動分を補正した静止領域に不規則な画素変化がない。移動キャラ、意図的アニメ、動く影は静止比較から分離する。
実機確認：同シーンを2回リセット・再生し一致を確認。縦横は端末の向き。性能測定は準備5秒＋測定10秒の自動終了まで待ち、結果コピーを縦持ち・横持ちで試す。M1でまとめて確認可。

[検証基盤・測定条件・回帰検査・短い実機手順](../15_V6-03検証基盤.md)を参照。時刻固定は現在存在する瞬き・感情・歩行・葉・水面模様へ適用する。未実装の水・粒子表現は新規開発しない。Three.js r128、通常時のv5相当、原本、衝突判定と照明方式を維持する。PNG保存保留、移動中の色のちらつき原因未確定は継続。
