# V6-11：点光源とスポットライトの単独検証

目的：手持ちランプ・街灯・妖精・懐中電灯の光と影を比較する。
依存：M3。
作業：点とスポットを別の検証シーンで実装。位置・色・強度・範囲・減衰・方向を実行時変更可能にする。影の有無と品質を切替え、1個から増やす測定を行う。
守る条件：全方向の点光源の影は複数方向の描画を含めて測定。影なしモードの壁越し照明を「不具合なし」と扱わない。手持ちライトの所有キャラを、自身の影で不自然に暗くしないよう検証する。
受け入れ条件：移動する光の色が背景・キャラに反映される。影が動き、輪郭と前後関係が安定。単独／複数、影あり／なしの同条件比較結果がある。
実機確認：ランプを持って壁沿いに移動、光る妖精を周回させる、懐中電灯を旋回。近距離の強い光と影を確認。M4へ。
