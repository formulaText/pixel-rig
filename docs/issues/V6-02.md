# V6-02：r128のままモジュール分割しv5を再現【節目M0】

目的：機能変更を混ぜず、ファイル分割後の基準版を確立する。
依存：V6-01。
作業：定数、シェーダー、素材、ワールド、キャラ、描画、入力、UIを分割。比較・焼き出しをdebugへ移す。原本の既定値・処理順・データ・色を維持。型定義は振る舞いを変えない範囲で付ける。
守る条件：壁際の既知問題もこのPRで直さない。カメラ、移動の丸め、色管理、影、顔マスク、デカールの順序を維持。TypeScript化を理由に新しい設計へ全面置換しない。
受け入れ条件：昼夕夜、影切替、感情6種、瞬き、模様の展開、解像度16/24/32/48、ドット倍率、比較、PNG焼き出しの機能一覧が揃う。元と同条件で静止画と移動を比較し、説明できない差分がない。ランダム動作は停止するなど条件を合わせる。
実機確認：v5と分割版を交互に開き、村・井戸・壁・樹木・水辺を確認。縦横、ドット倍率の端、8方向移動を比較。fps条件も揃える。既知問題と新規不具合を区別してM0承認を得る。

## 実機結果と区切り（2026-11-07、依頼者報告）

確認ビルド `gh-42343155272-1-6b97c72eee25`、確認コミット `6b97c72eee25d53b27788b33de9bf124e0d5fc20`、iPhone 17／Safari。

起動・手動移動・コミット一致は正常。背景・キャラ・重なり・8方向移動・縦横・倍率端と、照明／影／感情／瞬き／模様／解像度／顔／変換／自動歩行／比較更新は原本との差なし。線の欠けなし。PNG画面を閉じた後の移動も正常。

移動中の色のちらつきは原本・候補共通で未解決。横以外で確認し、横では目立たないが不発生とは断定しない。マップ端で位置固定・歩行アニメーションのみでは見られないが、原因は未確定。

PNG保存は両方で失敗し、OSダイアログの表示／ダウンロードでも先へ進めず、保存画像比較は未確認。依頼者は既存不具合として保留し、修正を後続研究の前提にしないと判断した。上記受け入れ条件を無条件に達成したとは記録しない。

解像度32・倍率4・昼・影ON・比較更新OFF・PNG画面を閉じる・録画停止で、表示fpsは縦横59〜61（おおむね60）。数分間の継続動作で追加問題なし。簡易表示の観察であり、厳密なフレーム時間測定や全条件の60fps保証ではない。

視覚表現研究と必要な描画・検証基盤を優先する判断を[09](../09_決定事項と検討状況.md)へ記録。色のちらつきを最終許容仕様・解決済みにはしない。[実機記録全文](../14_V6-02検証と実機確認.md)を参照。今回の資料更新は実装変更・後続Issue着手・Issueクローズ・マージ・再配信・昇格を含まない。
