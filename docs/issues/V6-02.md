# V6-02：r128のままモジュール分割しv5を再現【節目M0】

目的：機能変更を混ぜず、ファイル分割後の基準版を確立する。
依存：V6-01。
作業：定数、シェーダー、素材、ワールド、キャラ、描画、入力、UIを分割。比較・焼き出しをdebugへ移す。原本の既定値・処理順・データ・色を維持。型定義は振る舞いを変えない範囲で付ける。
守る条件：壁際の既知問題もこのPRで直さない。カメラ、移動の丸め、色管理、影、顔マスク、デカールの順序を維持。TypeScript化を理由に新しい設計へ全面置換しない。
受け入れ条件：昼夕夜、影切替、感情6種、瞬き、模様の展開、解像度16/24/32/48、ドット倍率、比較、PNG焼き出しの機能一覧が揃う。元と同条件で静止画と移動を比較し、説明できない差分がない。ランダム動作は停止するなど条件を合わせる。
実機確認：v5と分割版を交互に開き、村・井戸・壁・樹木・水辺を確認。縦横、ドット倍率の端、8方向移動を比較。fps条件も揃える。既知問題と新規不具合を区別してM0承認を得る。
