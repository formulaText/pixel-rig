# V6-03後：キャラクターの移動中色ちらつき

対象：[Issue #10](https://github.com/formulaText/pixel-rig/issues/10)。1 Issue・1 PR。V6-04の前に行う追加調査で、V6-04以降は未着手。

目的：姿勢・向き・照明と位置補正を揃えた比較で、移動中の色が変わる段階と原因を切り分ける。裏付けのある最小候補を初期OFFで公開する。

守る条件：Three.js 0.128.0、原本、衝突判定、照明方式を維持。全体ぼかし・時間平均・中間色置換・アニメ削除を導入しない。PNG保存保留。通常毎フレームreadPixels禁止。確認済み版保持。実機未確認を解消済み・採用済みとしない。

受け入れ：縦横斜め・方向・姿勢・位置固定歩行・カメラ・影／照明／輪郭・中間バッファを必要な組合せで比較。解像度16／24／32／48と代表倍率をCodex側で検査。変更前の症状を検出できる検査で候補の改善と残差を示し、背景・輪郭占有範囲・前後関係・意図的動作の退行を検査する。画像読出しの負荷は性能測定と別に記録。

[原因・比較候補・検査・実機手順](../16_キャラクター色安定性の調査.md)。候補Aは輪郭用深度の丸め位相を足元に固定する比較実験。合成前から変わる成分は未解決。キャラ相対深度の方式は正式仕様にしない。実機比較と採用承認後にマージ／昇格を別操作で判断する。
