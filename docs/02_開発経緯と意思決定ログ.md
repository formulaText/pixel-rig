# 02 開発経緯と意思決定ログ

この文書の本文はv1〜v5当時の記録です。「合意済み」や「必須」は当時の判断であり、現在の条件は [09](09_決定事項と検討状況.md) を参照してください。
特に楕円当たり判定は現在「試行案」、60fpsは研究目標、解像度の組み合わせは比較対象です。本文の過去の記述は経緯を示すため保持しています。


各バージョンの「作ったもの」「依頼者の評価」「決定事項」をまとめる。プロトタイプは prototypes/ に同梱。

---

## 技術検討(実装前)

- 3D→低解像度レンダーターゲット→後処理→整数倍拡大、という基本パイプラインを採用。
- 前例:SFC『スーパードンキーコング』(3Dプリレンダー)、『Dead Cells』(3Dを低解像度・AAなしで描画)。
- 課題として、色数制限、半透明の排除、輪郭線、ちらつき(サブピクセル移動)、顔の解像度不足を洗い出した。
- 依頼者の方針:SFC風は頭身と動きの参考であり、見た目は現代的なリッチさでよい。リアルタイム方式を本命とし、品質が足りなければ焼き出し方式も可。8方向・やや見下ろし。

## v1:キャラ単体のリアルタイム変換

**作ったもの**
- プリミティブで組んだデフォルメ人形(手続き的な歩行・待機モーション)。
- 変換ステップ①〜④の切り替え:①色数制限(色相シフト付きトゥーン階調+パレット量子化)、②半透明の排除(低解像度へ直接描画+α二値化)、③輪郭線(外周1px+深度/法線エッジ)、④ちらつき対策(歩行4コマ間引き・ピクセルスナップ・8方向スナップ)。
- 段階比較の表示、8方向×4コマのスプライトシート焼き出し。

**依頼者の評価**
- スマホで約60fps。④はONにしないとちらつく。ただしドットの大きさ5以上では④ONでもちらついた。
- 解像度は32がちょうどよい。16も見たい。

## v2:3Dフィールド化と顔表現の比較

**作ったもの**
- 村のフィールド(家・木・井戸・池・柵・台地)を3Dで作り、キャラと同じピクセル格子でドット絵化。
- 顔の表現3方式:3D形状/UVデカール/「ドット顔」(目の位置だけを3Dから求め、ドット絵の目を直接描き込む)。
- v1のちらつきの原因2つを修正:カメラとキャラを別々に丸めていたため奇数幅で1px揺れていた/キャンバスがデバイスピクセルの半端な位置に配置されていた。

**依頼者の評価**
- キャラのちらつきは解消。
- 顔はドット顔が最良(デカールは動きによって顔に見えなくなる)。まばたき等の表情アニメの仕組みがほしい。
- 背景がちらつく(特に横・斜め移動)。木の葉にキャラの頭がめり込む。
- 質感はノイズではなく、通常のドット絵のように書き込みで表現したい。地面・壁・水などはプロシージャルに。タイルチップを基本に、任意の箇所に特別な書き込みを置ける仕組みがよい。
- 影は「地面の色を1段暗くする」より半透明の乗算合成がよい(将来の動的照明の障害になるため)。パレット内の色に限定するこだわりは不要。

## v3:ちらつき根絶と質感の基盤

**決定事項(依頼者合意)**
- ロジック60Hz固定、移動量を整数ピクセルで管理、8方向移動は(1,1)のようにX/Yを同フレームで同時に動かす。
- 模様は「画面上の1ピクセル=模様の1マス」になる座標系で計算する。依頼者から「カメラの方角の真正面から投影すればよいのでは」という提案があり、これは数学的に同一の方式であることを確認した。

**作ったもの**
- 全模様を整数ピクセル座標で計算(背景ちらつきの原因=ノイズ境界と画素中心の一致、を解消)。
- 地面のタイルチップ(草・花畑・土・砂・石畳・水)、境界のノイズなじませ、水の波アニメ。
- 壁・屋根などへのピクセル模様(レンガ・横板・縦板・瓦・石積み)。
- 2D式の前後関係:小物とキャラは「足元を通る垂直な板」の深度で判定。
- 乗算の足元影、表情システム(自動生成の半目・閉じ目など)。

**依頼者の評価**
- 背景のちらつきは消えた。fpsは問題なし。
- 井戸(曲面)への投影は「絵を貼った」ようで違和感が大きい。依頼者案:オブジェクトとの距離に応じて投影を変形させれば疑似的に立体投影できるのでは → 曲面の展開マッピングと数学的に同等であることを確認し採用。
- 家の側面はカメラ角度的に描画されないので確認不可(正面見下ろし視点では妥当)。
- 壁に頭だけめり込む → 依頼者案:キャラをピルで包む当たり判定。
- 表情は32pxでも読み取りにくい。JRPGなら体全体の動き・吹き出し・汗マーク等の漫画的表現が自然。目を細める・眉の上げ下げ程度で十分。口は不要。
- 自動歩行時に障害物沿いでガクガク震える。横向き時に目が顔からはみ出す。

## v4:曲面マッピング・当たり判定・感情表現

**作ったもの**
- 円柱の展開マッピング(画素位置と軸からの距離から曲面座標を復元。強さ0〜100%)。線は「隣の画素とセルが変わるか」で判定し、圧縮されても消えない。
- ピル当たり判定(頭の幅0.48)、建物は屋根外形基準。
- 向き判定のヒステリシス(境界+10°)と最短保持(8ティック) → 自動歩行のガクガク解消。
- 目は肌の画素にだけ描き込む(色パスのα=0.6を肌の印に使う)。横向き時は中心側へ1px寄せる。
- 感情表現:頭上アイコン(♪ ! ? … 怒り 汗)+全身モーション+目(通常/細目/閉じ)と眉(吊り/困り)。

**依頼者の評価**
- 井戸は展開100%がしっくり。樽や幹はどの値でもよい(画面上の大きさが小さいと差が1〜2pxしか出ないため、と分析)。
- 頭のめり込みは解消したが窮屈。軒下に隠れられなくなったのも窮屈感の原因。将来NPCや複数キャラを出すことを考えると、背景の構造・配置に余裕を持たせる仕組みが必要。
- 感情表現はベースとしてOK。

## v5:深度ルール・樹木・描き込み層・照明

**決定事項**
- 依頼者の懸念:「層ごとに深度を消去して描く方式」は、画面回転・アイソメトリック・HD-2D化の障害になる → 1つの深度バッファの中で物体ごとに深度ルールを持たせる方式に変更。カメラ角度の固定値はパラメーター化する。

**作ったもの**
- 深度ルール:3D/手前の板/奥の板/地面。建物の壁は「奥の板」、屋根は3D。
- カメラ基底(右・上・手前)をユニフォーム化し、板・模様・曲面・地面タイルをすべてそこから計算。
- 異なる物体間の輪郭線は深度バッファ(描画上の前後)で、同一物体内は本来の深度で判定。
- プロシージャル樹木(ボロノイによる葉の塊、樹皮模様)。
- 手描きドット絵の描き込み層(地面置き/立て置き)。
- 照明:時間帯(昼/夕方/夜)、太陽のシャドウマップ、街灯の点光源(ディザ4段階)、発光するランタン。

**依頼者の評価**
- 建物まわりの前後関係は意図どおり。ただし**壁に隣接するとキャラが壁の上に描かれて不自然**(references の画像)。
- 木は成立しているが好みのデザイン・品質ではない(デザインが好みでない点は全体にも言える)。
- 光と影はディザ段階でなく、もっとリッチ(3D的リアル)にしたい。
- 地面・葉・素材の質感が単純で平面的。草もつまらない。
- fpsは問題なし。

**v5への追加要望(→ v6〜v9 のロードマップへ反映)**
- 草:1ドットのノイズを縦に短く伸ばした細かい草、3Dのファー(シェル)による草、風でなびくアニメーション、風の強さで天候や情感を表現。
- マップチップで斜め・カーブ(道・水たまり・池・川)。当たり判定も一致させる。
- 水:水面の歪んだ反射、透過した水底、疑似屈折、任意方向の水流、滝(垂直の流れ)、滝の裏を通るキャラの屈折、水しぶき。最終的にキャラが水中を歩く・泳ぐ。
- 照明:太陽・点光源に加え、スポットライト・面光源。影と光を3D的にリッチに。位置・明るさ・色を動的に変化(1日の流れ、街灯、窓の明かり、光る妖精、手持ちランプ、懐中電灯)。
- ネオンのような発光体(周囲を照らさないが光って見える)。
- ドット表現のパーティクル。
- 樹木:成長シミュレーションの単純化による枝の生成、メタボール的に融合した葉の塊、広葉樹・針葉樹、季節(葉のみ・花・果実・枯れ木)のパラメーター生成。

**v5問題への対応方針(合意済み)**
- 当たり判定を「画面の横方向は見た目の幅(約0.48)、奥行き方向は足元の幅(約0.3)」の楕円にし、壁を3D深度に戻す。詳細は 05_ロードマップv6-v9.md。
