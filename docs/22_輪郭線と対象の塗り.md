# 輪郭線と対象の塗り（Issue #18）

## 現行処理と比較候補

3Dの色・面法線／相対深度・深度バッファを作り、最終ドット処理で上下左右4近傍を比較する。同じ物体内は相対深度、異なる物体間は描画深度を使用する。従来の外周線は隣のキャラの外側1画素へ描くため、線の下は背景。内部境界線は後ろ側の画素を暗くするため、線を薄くすると後ろのパーツ色へ戻る。元のモデル色・深度に穴があるわけではない。

研究専用の「線と塗りの方式」を3択にする。初期値と既存保存設定は「従来」のままで、採用済みの通常描画Bを変更しない。

- **従来**：既存の結果をそのまま保持する比較元。
- **塗りを保つ（候補）**：従来の線の占有位置へ、手前側近傍パーツの色を塗りとして保持し、その上に線を重ねる。線の不透明度にかかわらず対象は不透明。前後が競合する近傍は、同じ物体なら相対深度、異なる物体なら実深度で手前の所有者を選ぶ。
- **内側に線（比較）**：外周を外へ延ばさず、自身の端の塗りに線を重ねる比較。全体寸法と見える塗りが小さくなるので、希望に対する標準案にはしない。

モデル一律拡大は顔・髪・首の接続や3D表示まで変更するため実装していない。候補は最終合成だけで塗りを保持し、格子・Bの深度精度・3D形状・衝突・移動速度・背景の輪郭仕様を変更しない。髪の色を境界へ保持した画素では、顔のスタンプもその所有者の肌マスクを参照し、目を髪より前へ描かない。3D確認は従来どおり輪郭なしの高解像度表示。

## 寸法・情報量と副作用

外周1画素を新しく外へ増やす方式ではなく、既存の線の占有画素へ塗りを足す。100%時の外周を基準に大きさを維持するが、線なしの従来描画を基準にすると塗りのシルエットは各端で最大1ドット増える。内部の境界画素も手前パーツの塗りになるので、線を消した際は後ろ側の塗りがその分隠れる。全パーツの露出面積を同時に同じにすることはできない。

合成図の検査：背景上の10×10の肌色領域に4×4の赤い手前パーツを配置する。従来100%と候補は外形12×12・占有140画素。候補は不透明度0/50/100%で同じ占有を維持し、赤境界の0%はRGBA `(220,35,50,255)`（背後の肌色ではない）。従来0%は10×10・100画素に縮む。内側比較は10×10・100画素で、100%時の線に覆われない元の塗りは48画素、従来と候補は84画素。

候補で塗りを補う色は、隣接する可視表面の色であり、隠れた3D表面を追加レンダリングした色ではない。極細部や斜面で色の延長が好みに合うかは実機比較が必要。ぼかし・時間平均・目のサイズ補正を使わない。

## 保存・負荷・状態

スキーマ4に方式を保存。1/2/3の研究設定は値・顔の投影を保持して移行し、線の方式を従来とする。元の保存文字列は読んだだけでは書き換えない。基準表示と通常復帰には候補が漏れない。

通常時は既存分岐。候補は既存の最終合成で近傍の所有者を比較する追加テクスチャ参照を行う。描画パス・モデル数・テクスチャ生成頻度を増やさず、毎フレームreadPixelsを追加しない。内側比較のみ4近傍を追加確認する。GPU実機負荷は未測定で、60fps達成を新候補について断定しない。画素比較のreadPixelsは自動検査だけで使用する。

## 確認手順

1. 「描画」→「線と塗りの方式」で「塗りを保つ（候補）」を選ぶ。
2. 外周線・内部線の不透明度を各0%・50%・100%へ。体が透けず、線を消すとそのパーツの色が見えるか確認する。
3. 「全体」の向き、「胴体・動き」の待機・歩行・縦移動・斜め移動で、細部、髪と顔、木との前後関係を確認する。

比較実装は方式の採用ではない。研究候補は実機確認前にマージ・昇格しない。確認済み版、原本v5、PNG保留、残差10条件と原因未確定のまばたき変化、V6-04前の計画を維持する。

## 実測と画像

依頼者から後送された図も直接確認した。上段の「薄い赤パーツ線から肌色が見える」状態と、下段の「赤い塗りの上の線」を区別する根拠として用い、図の下段の寸法をそのまま採用しない。

S32・正面・元の頭・静止の実描画では、従来100%と候補は14×24ドット・占有253画素。候補は0/50/100%で同じ占有。従来0%と内側比較は12×22・195画素。100%で線や顔スタンプ等に置換されず、元の表面RGBが残る画素は、従来／候補129、内側比較87（見える塗りの比較指標）。候補は前髪の境界にも髪色を保持するため、元顔パレットの可視画素は正面で10→8。目の元絵柄やサイズは変えず、髪の所有領域に顔を重ねない結果である。この細部の露出差は副作用として比較し、同じ見た目を完全維持したとは扱わない。内部線の色も、背後の色ではなく手前パーツ色に基づくため変わる。

[実キャラクター比較画像](validation/outline-character.png)：行は従来／候補／内側、列は0／50／100%。[赤パーツと肌色の合成図](validation/outline-synthetic.png)も同じ順序。[集計](validation/outline-results.json)に8方向の寸法・占有・元の表面色が残る画素数・顔色画素数を記録。

3形状×2顔×3動作×8方向＝144条件で、姿勢・時刻・向きを固定し、位置補正した縦・斜め移動を比較した。142条件は最終画素差分0。横に丸い頭・待機・右斜めの2顔では1画素差分が残り、従来も同じ画素に同じ差分数を持つ。色バッファの差分は0、法線／深度バッファに1画素差分があり、今回の輪郭処理で新しく差分位置は増えていない。既存10条件の残差とは別の研究形状の記録で、完全消失とはしない。各144条件の0/50/100%で元の色・深度・シルエットの変化0。マップ3箇所で元の色・深度とキャラ近傍以外の背景は不変。瞬き4時刻の位置補正比較も差分0。

最終ローカル検査：原本18件、型・ビルド・単体30件成功。候補選択と外周50%／内部0%の保存・再読み込み・復元、基準へ切替、通常復帰preciseを検査。候補での3D／ドット両表示でも、開いた目の閉じ目方式往復・顔全体位置往復の画像一致を確認。既存の目整合性検査、保存UI3サイズ、顔・頭72条件と9箇所重なり、通常Bの153条件×3バッファ一致も成功。CIと公開成果物の結果はPRの配信記録へ追記する。
