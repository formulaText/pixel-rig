# pixel-rig

Three.jsで、3Dキャラクターと背景を現代的でリッチなドット絵として描画する研究プロジェクトです。

このパッケージは2026-11-07時点の開発資料と、v1〜v5のリファレンス実装を収録しています。v6の実装・ビルド設定・配信ワークフローはまだ含みません。

## 現在の段階

対象は公開リポジトリ [formulaText/pixel-rig](https://github.com/formulaText/pixel-rig) です。Codexからリポジトリを確認し、この資料登録ブランチに展開済み資料を配置しました。mainへの統合は別途レビュー・マージ後に行われます。配信方式は未決定で、v6実装・実機確認は未着手です。
最初の開発目標は、Three.js r128のままファイル分割してv5の見た目・挙動を再現することです。
