# pixel-rig

Three.jsで、3Dキャラクターと背景を現代的でリッチなドット絵として描画する研究プロジェクトです。

v1〜v5の原本と現行開発資料に加え、TypeScript＋Viteによるv5再現アプリとV6-03検証基盤、原本検査、GitHub Actions／Pagesの配信基盤を収録しています。Three.jsは0.128.0を維持しています。

アップロード済みの [開発資料ZIP](pixel-rig-development-package.zip) を保持しています。`MANIFEST.sha256` は配布版の54ファイルを検証するための記録です。登録時に統合・更新した文書と検証方法は [資料更新記録](docs/13_資料更新記録.md) を参照してください。原本HTML・参考画像・保存用旧文書は配布版から変更していません。

キャラクターのルック研究は[統合候補](https://formulatext.github.io/pixel-rig/candidate/?study=look)で確認します。[工程1](docs/18_ルック研究基盤.md)／[工程2の調整範囲と短い確認手順](docs/19_顔編集と頭形状研究.md)。公開ビルドIDは対応PRの配信記録を参照。研究画面の実装は調整後のデザインの採用を意味しません。

現在の研究基準候補は依頼者のschema 5全文を保持し、[眉・動作姿勢の整合性を修正](docs/24_眉と動作姿勢の整合性.md)しています。細かなキャラの絵作りは区切り、次工程はV6-04の更新先／GPU診断の設計です。高い画素密度の比較要件をV6-07〜09へ反映。今回の実装は不整合修正までで、未承認の研究PRをマージ・昇格しません。
