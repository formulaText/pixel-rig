# pixel-rig

Three.jsで、3Dキャラクターと背景を現代的でリッチなドット絵として描画する研究プロジェクトです。

v1〜v5の原本と現行開発資料に加え、TypeScript＋ViteによるV6-02のv5再現アプリ、原本検査、GitHub Actions／Pagesの配信基盤を収録しています。Three.jsは0.128.0を維持しています。
