# pixel-rig

Three.jsで、3Dキャラクターと背景を現代的でリッチなドット絵として描画する研究プロジェクトです。

v1〜v5の原本と現行開発資料に加え、TypeScript＋Viteによるv5再現アプリとV6-03検証基盤、原本検査、GitHub Actions／Pagesの配信基盤を収録しています。Three.jsは0.128.0を維持しています。

[日常の配信運用](docs/07_リポジトリ構成と開発フロー.md)：依頼者は研究方針・実機確認・採用判断、Codexは実装・検査・GitHub操作・候補公開・結果確認・資料更新を担当します。描画変更のマージ・昇格は対象ビルドの明示承認後にCodexが代行します。候補公開では確認済み版を変更せず、昇格時は実機確認した成果物を再ビルドしません。依頼者が毎回Run workflowを操作する必要はありません。
