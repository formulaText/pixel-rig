# Pixel Rig プロジェクト 引き継ぎ資料

この資料一式は、Three.js を使って「3Dで動かしたキャラクターや背景を、リアルタイムに現代的なドット絵として描画する」技術検証(Pixel Rig PoC)の成果と、今後の開発計画を、別のAI開発環境へ引き継ぐためのものです。

本資料では、プロジェクトの依頼者を「依頼者」と表記します。

## 同梱物

- `prototypes/` … v1〜v5 のプロトタイプ(各1ファイルの単体HTML)。Three.js r128 を cdnjs から読み込むため、ネット接続環境でブラウザから直接開けば動作します。
- `references/v5_wall_adjacency_issue.png` … v5 で確認された「建物の壁に隣接したキャラが壁の上に描かれる」問題のスクリーンショット(04_既知の課題.md の課題1)。

## 現在地(要約)

- 最新は **v5**。「3Dで構築した村のフィールド+3Dキャラ」を、1つのピクセル格子でリアルタイムにドット絵化できている。
- スマホ実機で約60fpsを維持(依頼者の実機確認による)。
- 次は **v6(描画基盤の作り直し:低解像度ディファードレンダリング化など)** から着手することで合意済み。
- v6 以降はコード規模的に単体HTMLでは限界のため、**ファイル分割+ローカルサーバー(またはバンドラー)構成へ移行**することで合意済み。
