# 01 プロジェクト概要とビジョン

## 1. 目的

Three.js などの3D技術でモデル・モーション・背景を構築し、最終的な画面出力を「現代的でリッチなドット絵」に見せるリアルタイム描画技術を確立する。

対象はスマートフォンを含むブラウザゲーム。キャラクターは**ゲーム内でリアルタイムに動く**ことが前提(スプライトシートへの焼き出しは補助機能・比較用)。

## 2. 最終目標:RPG作成ツールの土台

このプロジェクトは単体のゲームを作るためだけのものではない。ここで確立した描画技術・データ構造を使って、**利用者が自由にJRPG風のゲームを作成できるゲーム作成ツール**を作ることが最終目標であり、本プロジェクトはその土台にあたる。

そのため、各機能は「特定のマップ専用の作り込み」ではなく、次の方針で設計することが望ましい。

- 地形・建物・植生・照明・水・パーティクルなどを**パラメーターやデータから生成できる**こと
- マップやオブジェクトの配置を**データ駆動**にできること(将来エディターから編集するため)
- NPCや複数キャラが同時に存在しても破綻しないこと(通路幅・当たり判定・前後関係)

詳細は 08_ゲーム作成ツール構想.md を参照。

## 3. 目指す見た目

| 項目 | 方針 |
|---|---|
| 頭身・動き | SFC時代のJRPG(2〜2.5頭身のデフォルメ体型、歩行4コマ程度のリズム) |
| 画面の質感 | 近年のドット絵ゲームのようなリッチさ(依頼者が挙げた例:「Sea of Stars」、HD-2Dのキャラクター) |
| ドットの大きさ | 昔のゲームのように目立たなくするのではなく、ドット絵であることをあえて強調する大きめのドット |
| キャラの解像度 | 32px程度がちょうどよい(48px以上は「日本のゲーム感」が薄れるという評価)。16pxも比較用に残す |
| 視点 | やや見下ろしの正面視点・8方向移動。まずは2D表現を優先 |
| 将来の視点拡張 | 規定角度での画面回転、アイソメトリック、HD-2D風背景も視野に入れる(障害にならない設計が必要) |
| 光と影 | ディザによる段階表現は「選択肢の一つ」としてはよいが、依頼者はもっとリッチで3D的にリアルな光と影を望んでいる |
| 質感 | 現状は単純で平面的。ドット絵としての書き込み量・リッチさを増やしたい |

## 4. 動作環境の前提

- スマートフォンのブラウザで 60fps を維持すること(v5時点で達成。今後も維持が必須条件)
- WebGL(Three.js)
- 画面は低解像度でレンダリングし、整数倍に拡大して表示する(ドット1つ=整数個のデバイスピクセル)
